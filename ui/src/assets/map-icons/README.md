# Map icons

`grocery.svg` (a shopping cart) and `shop.svg` (a storefront) are from Maki, Mapbox's icon set for
maps: https://github.com/mapbox/maki (v8.2.0, `icons/`). Maki's icons are released under CC0 1.0, so
they carry no attribution requirement.

They are drawn onto the supermarket pins in `ui/src/components/map/groceryIcons.js`.
